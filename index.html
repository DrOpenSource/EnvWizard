Frequently Asked Questions

Does EnvWizard transmit any environment variables or code?

No. Everything runs locally: port scanning uses native system commands (netstat, lsof, ss) and code checks run inside your editor. The only network request is a one-time license check with Gumroad when you activate Pro. Zero telemetry is collected.

How does the Pro License work?

Pro launches with v0.2 as a $9.99 one-time purchase: a personal license for all your own machines that never expires, with 30-day refunds and no subscription. It is not on sale yet. Everything in the free version stays free.

Will it accidentally kill system daemons or Docker?

EnvWizard always shows what is holding a port and asks first. It refuses to stop programs on its protected list (your editor, Docker, WSL relays and system processes), and Clean Slate leaves databases like Postgres and Redis alone.

Which code editors are supported?

EnvWizard works across VS Code, Cursor, and Google Antigravity. It is distributed via the Visual Studio Marketplace and Open VSX.
