Frequently Asked Questions

Does EnvWizard transmit any environment variables or code?

No. EnvWizard operates completely offline. Port scanning uses native system commands (netstat, lsof, ss) and AST checks run locally in your editor process. Zero telemetry is collected.

How does the Pro License work?

Pro is a $9.99 one-time purchase with no subscriptions. Each license allows activation on up to 3 personal developer machines (e.g. work laptop, home PC, desktop).

Will it accidentally kill system daemons or Docker?

No. The Protected Process Shield has an un-bypassable blacklist protecting Docker, operating system shells, window servers, and IDE instances. If an unrecognized process holds a port, EnvWizard shows an approval card before taking action.

Which code editors are supported?

EnvWizard works across VS Code, Cursor, and Google Antigravity. It is distributed via the Visual Studio Marketplace and Open VSX.
